# Working in this repository

Read [resources/requirement.md](resources/requirement.md) before changing this
repository. It defines the development scope, task contracts, and local skill
routing.

For writing tasks, use the bundled
[Humanizer skill](resources/skills/humanizer/SKILL.md). For candidate instructions,
also use [instruction-writing](resources/skills/instruction-writing/SKILL.md).

After completing `harbor check`, use
[task-rating](resources/skills/task-rating/SKILL.md) to assess the findings and
record supported dimension scores in `task.toml` metadata and the task README.
