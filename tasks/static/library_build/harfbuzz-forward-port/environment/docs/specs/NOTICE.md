# Notice: the specification notes in this folder

The notes in `aat/`, `opentype/`, `scripts/` and `unicode/` are our own restatements of
published specifications, written for the engineers who build and maintain this product.
Each note covers one source page and names it on its `Source:` line. The notes condense,
reorder and explain what the sources define; they are not copies, translations or official
versions of the sources, and the publishers have not reviewed or endorsed them.

- **The sources govern.** Where a note differs from its source, leaves something out, or
  predates a later revision of the source, the source is authoritative.
- **What is carried over.** No source text is reproduced beyond names and titles, tables of
  identifiers and values (tags, code points, character and property names, field layouts,
  flag values, constants) and formal rules (grammars, regular expressions, boundary rules).
  All other wording is ours.
- **Copyright** in each source stays with its publisher: Microsoft for the OpenType
  specification and the script development pages on Microsoft Learn (pages marked
  "(c) Microsoft 2026"), Apple Inc. for the TrueType Reference Manual (pages marked
  "Copyright (c) 2026 Apple Inc. All rights reserved."), and Unicode, Inc. for Unicode
  Standard Annex #29 (marked "(c) 2004-2026 Unicode, Inc."). OpenType is a registered
  trademark of Microsoft Corporation, TrueType is a trademark of Apple Inc., and Unicode is a
  registered trademark of Unicode, Inc.
