# Paired rollout example

The paired_example.hdf5 file is an authored example of the documented native
robomimic-layout study. It contains calculated MuJoCo slider demonstrations.
policy_example.json shows a frozen controller with named observations and
several control timing profiles.

The recordings and MJCF were authored for this benchmark and are provided
under CC0. No original RoboTurk or robomimic recordings are included.
