# TUM VI room1 pose excerpt

The CSV contains 80 decimated motion-capture poses from room1 of the TUM VI benchmark by David Schubert, Thore Goll, Nikolaus Demmel, Vladyslav Usenko, Jörg Stückler and Daniel Cremers. The original data is CC BY 4.0. It retains the original time values and motion-capture pose values as represented by the source CSV. It includes every ninth row beginning at zero-based source data row 2240 and ending before row 2960. The authoring verifier applies a new stereo/IMU transform and seeded observations over these motions. The benchmark receives feature matches and pose tracks at the estimator boundary.

- [Official TUM VI dataset and CC BY 4.0 license](https://cvg.cit.tum.de/data/datasets/visual-inertial-dataset#license)
- [TUM VI benchmark paper](https://arxiv.org/abs/1804.06120)
- [Room1 CSV extraction used as source](https://github.com/BahMoh/TUMVI-IMU-only-Dataset-room1-to-room6/blob/master/dataset-room1_512_16_gt.csv)
