# Source code contents

Discover what's included in OpenFOAM, including our source and pre\-compiled
distributions.

After installation you'll find the main directories:

* [src](https://gitlab.com/openfoam/core/openfoam/-/tree/OpenFOAM-v2606/src): the core OpenFOAM libraries
* [applications](https://gitlab.com/openfoam/core/openfoam/-/tree/OpenFOAM-v2606/applications): solvers and utilities
* [modules](https://gitlab.com/openfoam/core/openfoam/-/tree/OpenFOAM-v2606/modules): Core extensions
* [plugins](https://gitlab.com/openfoam/core/openfoam/-/tree/OpenFOAM-v2606/plugins): Community contributions and test code
* [tutorials](https://gitlab.com/openfoam/core/openfoam/-/tree/OpenFOAM-v2606/tutorials): test\-cases that
demonstrate a wide\-range of OpenFOAM functionality
* [doc](https://gitlab.com/openfoam/core/openfoam/-/tree/OpenFOAM-v2606/doc): documentation

Follow [this link](https://gitlab.com/openfoam/core/openfoam/-/tree/OpenFOAM-v2606/) to navigate to the source code repository
online.
