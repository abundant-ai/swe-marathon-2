# Battle royale

Build a realistic 3D battle royale in Unreal Engine 5 for two human players who play only as opponents.

- Implement the requirements in all ten component instructions below as one complete game.
- Each component folder contains its instruction and local reference images. Use the images for visual guidance; the written requirements define the required behavior. Extra features visible in an image are not required.
- Aim for believable proportions, materials, lighting, and animation. Choose the camera perspective, controls, weapon balance, and match pacing.
